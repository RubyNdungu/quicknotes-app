# QuickNotes App

A responsive, single-page web application for capturing, categorizing, and managing quick thoughts and ideas. Built for Day 4 Part 2 of Web Foundations.

## Features

- **Add Notes:** Create notes with specific categories (Personal, Work, Study).
- **Validation:** Prevents empty submissions and limits notes to 200 characters.
- **Live Word Count:** Dynamically tracks characters and words as you type.
- **Search Functionality:** Real-time, case-insensitive search to filter displayed notes.
- **Persistent Data:** Notes are saved to the browser's `localStorage` so they remain after refreshing.
- **Delete & Clear All:** Remove individual notes or clear the entire list with a confirmation prompt.
- **Responsive Design:** Uses CSS Flexbox and media queries to adapt cleanly to mobile screens (under 600px).

## Technologies Used

- HTML5 (Semantic Structure)
- CSS3 (Flexbox, Media Queries, Custom Styling)
- JavaScript (DOM Manipulation, Array Methods, LocalStorage)

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser or use the VS Code Live Server extension.
